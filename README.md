# 📖 Artificial-Window-ZOE – Description & Usage

---

## 📌 Overview

**Artificial-Window-ZOE** is a tool that captures any running window (such as games, launchers, or fullscreen apps) and displays it inside a **borderless window** within the app itself.

It is designed to work seamlessly with the **ZOE floating menu**, allowing users to access clipboard notes while gaming or using fullscreen applications.

---

## 🎯 Key Features

- Capture any visible window from the taskbar
- Display the captured window as **borderless** inside the app
- Toggle between **windowed** and **maximized** (full-screen without borders) using `Ctrl+F` or `F11`
- Restore the captured window to its original state with the **Release** button
- Fully compatible with the **ZOE floating menu** (`Ctrl+Shift+Z`)
- Works with fullscreen games (Minecraft, TLauncher, etc.)

---

## ⌨️ Hotkeys

| Key | Action |
|-----|--------|
| `Ctrl+F` or `F11` | Toggle Maximize / Restore |
| `Esc` | Exit fullscreen mode (app stays open) |

---

## 🚀 How to Use

1. Run **Artificial-Window-ZOE** (auto-fullscreen)
2. Select a window from the list (game / launcher)
3. Click **Catch**
4. The window appears borderless inside the app
5. Use `Ctrl+F` or `F11` to maximize or restore
6. Press `Ctrl+Shift+Z` to open the **ZOE floating menu**
7. Click **Release** to restore the window back to normal
